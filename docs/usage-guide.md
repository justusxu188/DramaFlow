# FrameFlow 使用说明

> 短剧投流素材 AI 生产工作台
> 适用版本：main 分支（2026-08 之后版本）

FrameFlow 是一套面向短剧投流场景的 AI 素材生产系统：上传原剧后，系统自动完成剧情理解、爽点提炼、高光剪辑、AI 前贴脚本创作、AI 前贴视频生成与最终合成，产出可直接投放的广告素材。底层使用火山引擎 Ark（豆包大模型）、Seedream（文生图）、Seedance（视频生成）、AI MediaKit（剪辑/字幕/合成）与 TOS（对象存储）。

## 1. 账号与登录

### 1.1 首次初始化

系统第一次启动、还没有任何账号时，访问任意页面会自动跳转到初始化页 `/setup`：

- 填写 **姓名**、**用户名**（3–40 个字符）、**密码**（至少 8 位）；
- 点击「完成初始化」，该账号即为系统的**首个管理员**；
- 初始化完成后，历史上遗留的未归属项目会自动归到该管理员名下。

> 初始化页仅在系统无任何账号时可用；已有账号后访问 `/setup` 会自动跳转到登录页。

### 1.2 登录与退出

- 登录页 `/login`：输入管理员分配的用户名与密码，点击「登录」；
- 登录成功后会话保持 **7 天**，期间无需重复登录；
- 点击侧边栏底部的「退出」即可注销当前会话。

### 1.3 角色与权限

| 能力 | 管理员 | 普通用户 |
| --- | --- | --- |
| 创建项目、上传素材、发起生产 | ✅ | ✅ |
| 查看项目范围 | **全部项目** | **仅自己创建的项目** |
| 系统设置（服务状态/生产默认值） | ✅ | ❌（侧边栏不显示入口） |
| 用户管理（建号/重置密码/停用） | ✅ | ❌ |

普通用户账号由管理员在「系统设置 → 用户管理」中创建，不支持自助注册。

## 2. 界面导航

登录后左侧为固定侧边栏，自上而下：

- **项目中心**（`/`）：项目列表、新建项目、生产数据总览；
- **创作工作台**：
  - **创作总览**（`/production`）：四种创作流程的入口卡片 + 最近项目；
  - 四种流程直达：全链路素材创作、高光前贴创作、批量高光剪辑、视频后期剪辑；
- **素材库**（`/library`）：按项目归档全部素材；
- **任务中心**（`/tasks`）：全部后台任务与状态；
- **系统设置**（`/settings`，仅管理员可见）；
- 底部：当前用户名、角色（管理员/普通用户）、退出按钮。

进入某个项目后，侧边栏的创作流程入口会带上当前项目上下文，直接在该项目内打开对应工作流。

## 3. 项目中心

项目中心是登录后的首页。

### 3.1 数据总览

顶部四张指标卡（均来自真实任务数据）：

- **本周生成素材**
- **优质素材占比**
- **平均生产时长**
- **运行中任务**

### 3.2 新建项目

1. 点击「新建项目」，在弹窗中填写：
   - **剧目名称**（2–80 字，如「我的短剧项目」）；
   - **题材类型**（如「都市逆袭 / 古风种田」）；
2. 可选：在弹窗中直接选择上传 **源视频 / 图像资产 / 高光剪辑**（点击或拖拽文件）；
3. 选择「**创建并后台上传**」（素材在后台继续上传，可立即进入其他页面）或「**创建并进入**」。

项目创建后进入项目工作区；集数由实际上传的分集文件自动统计。

### 3.3 项目状态与操作

项目状态有四种：**待上传、待生产、生产中、已完成**。

- 支持按剧目名称或题材**搜索**；
- 每个项目行的「**⋮**」菜单可直接进入四种创作流程；
- 点击项目进入**项目档案页**（见下）。

### 3.4 项目档案页

项目档案页（`/projects/项目ID`，不带创作流程参数时）汇总该项目的全部资产与历史：

- **项目素材**统计：原视频、图像资产、正式高光、精选 AI 前贴、精选成片数量；
- **生产批次**归档：每个批次折叠展示，包含剧情片段数、爽点故事线数、脚本数、未完成任务数，以及高光/脚本/前贴/成片数量；
- 批次内可直接预览每条视频（Mediakit 高光视频、AI 前贴视频、完整成片视频）；
- AI 前贴视频可展开查看 **Seedance 实际提交提示词**（按分段展示）；
- 每条视频可「**设为精选 / 取消精选**」——精选后进入素材库对应文件夹，供后续复用或下载。

## 4. 素材上传与管理

系统素材分三类入口上传，全部经浏览器直传 TOS 对象存储，支持进度显示与失败重试。

### 4.1 源视频（原始剧集）

在项目工作区顶栏点击「**上传原始剧集**」，支持两种方式：

| 方式 | 说明 |
| --- | --- |
| **分集批量上传** | 一次选择多集 MP4/MOV；系统自动从文件名识别集数并排序，上传前可手动修正集数 |
| **整剧单文件** | 只上传一个整剧文件；后续可在剧情理解阶段做场景/分集切分 |

- 格式要求：`.mp4` / `.mov`（单文件最大 10 GB）；
- 上传列表逐文件显示大小、进度百分比、状态（待上传/上传中/完成/失败），失败可单文件重试；
- 可「稍后上传」，已完成的文件不受影响；
- 上传完成后系统自动读取视频时长。

**选择本次生产的素材**：顶栏「**选择素材**」弹窗中勾选本次生产使用的源视频，支持全选/清空，**单次生产最多选择 30 个**；新上传的视频会自动纳入选择。

### 4.2 图像资产（角色妆照）

在素材库中为项目添加角色图片，三种来源：

1. **上传角色图片**：直接上传 `.jpg / .jpeg / .png / .webp` 图片；
2. **生成角色图片（文生图）**：填写角色名称、妆造名称、画面类型（正面/侧面/半身/全身/其他）、提示词，选择模型与宽高比后由 Seedream 生成；
3. **视频截图生成**：选择项目内源视频与时间点抽帧，再基于截图生成角色图；也可选择参考图模式。

可将某张图标记为「**基准图**」。图像资产按**角色 → 妆造**分组展示，并标注来源（文生图/视频截图/用户上传/剧情确认）。

### 4.3 高光剪辑

在素材库中点击「**上传高光剪辑**」上传视频文件，上传后标记为「**用户高光**」；系统通过 MediaKit 自动剪出的高光标记为「**MediaKit 高光**」。高光可关联同项目源视频，也可独立存在（用于高光前贴创作）。

## 5. 四种创作流程

在「创作总览」页或项目菜单中选择流程。四种流程对应不同的起点与阶段：

| 流程 | 适用场景 | 阶段 | 执行方式 |
| --- | --- | --- | --- |
| **全链路素材创作** | 从原剧到最终广告成片，跑完整条流水线 | 生产设置 → 剧情理解 → 爽点故事线 → 高光剪辑 → AI 前贴脚本 → AI 前贴视频 → 最终成片 | 人工 / Agent |
| **高光前贴创作** | 已有高光视频，只需制作前贴并合成广告片 | 生产设置 → 剧情理解 → 爽点故事线 → AI 前贴脚本 → AI 前贴视频 → 最终成片 | 人工 / Agent |
| **批量高光剪辑** | 从原剧批量剪出可复用的高光素材 | 生产设置 → 高光剪辑 | — |
| **视频后期剪辑** | 对已有视频做字幕、擦除、调速、增强等后期处理 | 独立工作台（见[第 9 节](#9-视频后期剪辑工作台)） | — |

### 执行方式：人工 / Agent

全链路与高光前贴流程的顶栏可切换执行方式：

- **人工**：脚本生成后需人工审阅、编辑、确认，再逐条提交前贴视频生成；
- **Agent**：脚本生成后系统**自动确认脚本并自动提交 AI 前贴视频生成**，人物参考图自动绑定；若人物方式为「使用剧中人物」但缺少对应角色的图像资产，任务会暂停并提示缺少哪些人物的图片，补齐后重试即可。

## 6. 生产设置（生产设置阶段）

每个流程的第一个阶段是「**生产设置**」。这里的参数在**点击启动时快照固化**到该生产批次，之后修改全局默认值不影响已启动的批次。

阶段导航上若显示「**未保存**」，表示有改动未保存；可点击「**保存生产设置**」单独保存（后续生成读取这组设置）。

### 6.1 高光选择（仅高光前贴创作）

- 点击「**从素材库选择**」，勾选本次生产使用的高光视频（显示名称、来源、时长）；
- 若项目同时有原剧：前贴脚本复用同项目原剧的剧情理解与爽点故事线，并结合每条高光前 10 秒生成；
- 若项目没有原剧：系统完整理解选中的高光视频，提炼剧情与爽点后再生成。

### 6.2 剧情策略与脚本表达（批量高光剪辑无此组）

- **爽点故事线数量**：1–6；
- **每个高光脚本数**：1–6（预计脚本总数 = 高光成片总数 × 每个高光脚本数）；
- **前贴脚本预估时长范围（秒）**：最小不低于 3 秒；
- **前贴表达类型**（可多选，含 11 种预设 + 自定义）：
  反常台词悬念、超自然异能猎奇、极致身份反差、生死危机开场、违和奇观、工程或自然奇观、负面冲击诱饵、荒诞喜剧或离谱数据、证据实锤前置、结果前置倒叙、自定义（可直接指定希望的前贴类型、钩子结构与视觉方向）；
- **前贴与正片关系**（可多选）：剧情强关联、剧情延展、强引流性质、强引流+剧情延展、网络热点复刻；单次生成多个脚本时，每条脚本从已选关系中独立取一种。

### 6.3 高光剪辑（高光前贴创作无此组）

- **素材类型**：
  - 真人短剧（建议单条时长 60–720 秒）；
  - AI 漫剧 / 仿真人剧（建议单条时长 30–300 秒）；
- **剪辑模式**：混剪 / 跳剪（推荐，适合投流）、顺剪（适合剧情回顾）；
- **目标时长（秒）**与**输出视频数**：
  - 系统读取所选视频总时长后才允许填写；
  - 两项会互相给出**推荐值**与**建议上限**（按总时长的 75% 估算），仅供参考；
- **精彩前置（智能精彩前置）**：开启（混剪推荐）/关闭；顺剪建议关闭，开启时剪辑模式会自动切换为混剪。

### 6.4 AI 前贴视频（批量高光剪辑无此组）

- **人物生成方式**：
  - 使用剧中人物（需在素材库准备对应角色妆照）；
  - 新创人物资产；
  - 纯文生视频；
- **视频模型**：Seedance 2.5（单段最长 30 秒）、Seedance 2.0 / 2.0 Mini / 2.0 Fast（单段最长 15 秒）；超长脚本会自动分段生成；非默认模型需在服务端配置对应 Ark Endpoint；
- **生成字幕**：否 / 是。选择「是」后可设置：
  - 字幕字体：思源黑体、庞门正道、站酷快乐体；
  - 字幕字号：12–160；
  - 字幕颜色（取色器或十六进制色值）；
  - 字幕位置：底部居中、顶部居中、画面居中、下方三分之一；
- **分辨率**：480p / 720p / 1080p；
- **宽高比**：16:9 / 4:3 / 1:1 / 3:4 / 9:16 / 21:9（投流竖屏通常选 9:16）。

### 6.5 启动生产

- 主按钮根据当前状态显示「**开始生产**」或「**新建生产批次**」；
- 存在进行中的批次时，旁边出现「**继续当前批次**」按钮；
- 素材选择或配置相对当前批次发生变化时，新建批次会弹出**确认弹窗**（旧批次产物保留在自己的版本中，不会被覆盖）；
- 批量高光剪辑启动后，高光完成会**自动保存到素材库**。

## 7. 流水线各阶段说明

阶段导航条实时显示每个阶段的状态：**等待、运行中 N、已完成、失败、未保存、失效 N**，以及脚本/前贴的计数（如「总数 6 · 已确认 3 · 运行中 2」）。

### 7.1 剧情理解

- AI 分析所选源视频（或高光视频），输出故事线、剧情片段、角色信息；
- 同一项目内剧情理解与爽点故事线为**共享上下文**；
- 可点击「**重新理解**」提交重跑（有任务运行时禁用），完成后更新共享理解结果。

### 7.2 爽点故事线

- 基于剧情理解提炼爽点故事线（数量由生产设置决定）；
- 若有失败任务，可一键「**重试失败任务**」。

### 7.3 高光剪辑

- 展示本批次产出的高光视频，可预览；
- 每条高光可「**设为精选**」，精选后进入素材库「高光剪辑」文件夹；
- 若历史高光视频已失效（源文件被删等），阶段会标记「失效」，按提示回到生产设置发起新批次即可。

### 7.4 AI 前贴脚本

- 脚本按高光分组，顶部可切换当前高光；
- 每条脚本可**在线编辑**（标题、镜头画面、口播、衔接等）并**保存**；
- 脚本状态为「草稿」时需**确认**后才能用于生成前贴视频；支持勾选多条批量确认；
- 不需要的脚本可删除（有确认弹窗）；
- 可按当前页面的生产设置「**重新生成脚本**」；
- 点击脚本的「去生成前贴」会自动跳到 AI 前贴视频阶段并定位到该脚本。

### 7.5 AI 前贴视频

- 为已确认脚本**编译生视频提示词**（可编辑、保存）；
- 「使用剧中人物」模式下，需为脚本中出现的每个角色**绑定图像资产**（选择某张角色妆照，或选择纯文生视频）；
- 点击生成后提交 Seedance 视频任务，按模型分段上限自动分段；
- 生成中的脚本显示运行状态，失败可单条重试；
- 生成完成的前贴视频可预览、**设为精选**，并可发起与高光的**合成**。

### 7.6 最终成片

- 展示「AI 前贴 + 高光」合成后的完整广告成片；
- 可预览、设为精选（进入素材库「成片视频」文件夹，可下载）；
- 若前贴视频失效，按提示回到 AI 前贴视频阶段重新生成。

### 7.7 失败处理

- 任一阶段任务失败时，阶段下方出现错误提示条，显示失败原因，可：
  - 「**重试**」：重新提交该任务；
  - 「**忽略**」：本页不再提示该失败（记录在浏览器本地）。

## 8. 生产批次与版本管理

- 每次启动生产都会创建一个**生产批次（生产版本）**，按创建时间编号（如 2026-08-31 17:46 · 0001）；
- 顶栏右侧「**生产版本**」下拉可查看并切换历史批次，切换后页面展示该批次的产物与配置；
- 切换素材选择或修改生产设置后启动，会创建**新批次**，旧批次产物完整保留、互不覆盖；
- 项目档案页（[3.4](#34-项目档案页)）可回溯所有批次的中间过程、候选结果与完整提示词。

## 9. 视频后期剪辑工作台

「视频后期剪辑」是独立工作台，用于对已有视频做后期处理。

**基本流程**：

1. 左上角**选择项目**，项目内视频出现在素材区；
2. 将视频「**加入轨道**」（可多选、可设为主预览、可从处理范围移除）；
3. 在轨道上移动播放头可**跨视频预览**，定位后**分割**并删除不需要的片段，导出时自动合并；
4. 选择工具对「当前处理片段」执行处理，处理结果自动替换到轨道。

**可用工具**：

| 工具 | 说明 |
| --- | --- |
| **裁剪与拼接** | 跨视频分割、删除片段，最终「裁剪并拼接」导出合并视频 |
| **字幕擦除** | 使用精细化 V5 模型自动识别并无痕擦除中英文硬字幕 |
| **添加字幕** | 先「识别语音字幕」（ASR）→ 在线校对字幕文本 → 设置字幕样式 →「确认字幕内容」→「生成字幕视频」；字幕画面**通过验收后**才允许拼接，未通过会禁止保存与拼接 |
| **音视频调速** | 0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x / 3x |
| **画质增强** | 大模型画质增强，可选择目标分辨率 |
| **添加明水印** | 即将上线 |

> 注意：切换处理范围会清空当前字幕、撤销记录和已生成结果，系统会二次确认。

## 10. 素材库

素材库（`/library`）按项目分组归档，每个项目包含五个文件夹：

1. **源视频**：整剧源片 / 第 N 集，显示文件大小与时长，可预览、删除；
2. **图像资产**：按角色分组的妆照，标注来源与基准图；可在此上传角色图片、生成角色图片（文生图/视频截图/参考图）；
3. **高光剪辑**：MediaKit 高光与用户高光，区分「已关联源视频 / 独立高光」；可上传高光剪辑；
4. **AI 前贴视频**：被设为精选的前贴视频，可预览、下载、删除；
5. **成片视频**：被设为精选的最终成片，可预览、下载、删除。

页头统计全部项目的素材总量：项目数、源视频、图片、高光、前贴、成片数量。

## 11. 任务中心

任务中心（`/tasks`）列出系统全部后台任务，每次打开/刷新页面都会读取最新状态（项目工作区内的阶段视图则会在任务运行期间自动轮询刷新）。

- **工作流**列：全链路素材创作 / 高光前贴创作 / 批量高光剪辑；
- **任务类型**（流水线阶段）：
  剧情理解（故事线分析）、高光剧情理解、共享剧情上下文、爽点提炼、高光剪辑、高光开头理解、前贴脚本、AI 前贴视频、AI 前贴后期处理、合成成片；
- **后期处理任务**：字幕识别、字幕擦除、添加字幕、画质增强；
- **任务状态**：

| 状态 | 含义 |
| --- | --- |
| 排队中 | 已提交，等待 Worker 调度 |
| 运行中 | 正在执行 |
| 成功 | 已完成 |
| 失败 | 执行出错，可在项目工作区重试 |
| 结果异常 | 任务已结束，但本次生成产物与任务记录无法对应，请重试 |

点击任务可跳回对应项目的创作工作区。任务运行期间不影响打开其他项目或发起新的生产批次。

## 12. 系统设置（管理员）

系统设置（`/settings`）仅管理员可见，分三部分。

### 12.1 服务状态

五张服务卡片实时显示各依赖的配置状态（**已配置 / 待配置**）：

| 服务 | 用途 |
| --- | --- |
| **Ark / Seedance** | 豆包大模型（剧情理解、脚本）与 Seedance 视频生成 |
| **AI MediaKit** | 视频切分、高光剪辑、字幕、合成 |
| **私域虚拟人像** | 自定义虚拟人像入库与 Seedance 可信引用 |
| **TOS 对象存储** | 素材与成片存储、浏览器直传 |
| **MySQL** | 数据库（本地持久化模式下可不配置） |

页面顶部同时显示当前运行模式：**真实模式**（接入真实云服务）或**模拟模式**。

### 12.2 生产默认值（创意设置）

配置新项目、新批次的默认参数，项目启动时仍可在生产设置中调整；**任务启动时会快照参数，之后全链路不受全局配置变化影响**。

可配置项包括：

- 爽点故事线数量、每条故事线脚本数；
- 前贴表达类型、前贴与正片关系；
- AI 前贴人物方式、默认图片模型（Seedream 5.0 Pro / Lite）、默认视频模型；
- 生成字幕开关及字幕字体、字号、颜色、位置；
- 高光目标方式（按输出数量 / 按单条时长）及目标值、剪辑模式（混剪/顺剪）、视觉模板（无 / 热门短剧 1–5）；
- **高光片段筛选要求、高光开头筛选要求、高光结尾筛选要求**（文本要求，指导 AI 选片）；
- 提示语（留空或输入"无"表示不需要）；
- 智能精彩前置开关、钩子最小时长 / 最大时长（1–15 秒）、钩子最低高光分（1–5）；
- **AI 前贴三阶段 System Prompt**（专业调优）：
  - 01 创意提案：剧情输入 → 差异化创意；
  - 02 视频脚本：创意提案 → 可审核脚本；
  - 03 生视频提示词：确认脚本 → Seedance 指令（分「无字幕」「有字幕」两版）；
- 底部可「**恢复默认**」或「**保存配置**」。

### 12.3 用户管理

- 顶部显示账号总数；
- **创建用户**：填写姓名、用户名（3–40 字符）、初始密码（至少 8 位）、角色（普通用户 / 管理员）；
- 每个账号一行，显示姓名、@用户名、角色、启用状态（已启用 / 已停用）；
- 「**重置密码**」：为该账号设置新密码（至少 8 位）；
- 「**停用 / 启用**」：停用后该账号无法登录；**当前登录的管理员不能停用自己**。

## 13. 常见问题

**Q：登录时按钮一直停在「正在提交」？**
A：多为浏览器缓存了旧版本页面。请强制刷新浏览器（Mac：`Cmd + Shift + R`，Windows：`Ctrl + Shift + R`）后重新登录；当前版本会话 Cookie 已按访问协议（HTTP/HTTPS）自动适配。

**Q：上传视频失败怎么办？**
A：上传采用浏览器直传 TOS，失败时文件行会显示 HTTP 状态码与错误信息，可点击重试按钮单独重传；若所有文件都失败，请联系管理员检查 TOS 存储桶配置与网络。

**Q：任务失败 / 结果异常怎么办？**
A：在对应阶段点击「重试」即可重新提交；也可到任务中心查看全部任务。若 Agent 模式提示「缺少人物图像资产」，请先到素材库为提示中的角色上传/生成妆照，再重试。

**Q：改了生产设置，正在跑的批次会变吗？**
A：不会。设置在批次启动时快照固化；改动只影响之后启动的新批次。历史批次可通过「生产版本」下拉随时回看。

**Q：精选的视频在哪里找？**
A：高光、AI 前贴、成片点「设为精选」后进入素材库对应文件夹；项目档案页保留每个批次的全部候选产物，未精选的也不会丢失。

**Q：普通用户为什么看不到某些项目？**
A：普通用户只能看到自己创建的项目；管理员可见全部项目。需要协作时请联系管理员调整账号或在管理员账号下统一管理。
