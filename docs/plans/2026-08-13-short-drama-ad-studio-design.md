# 短剧投流素材工作台设计

## 目标

构建一个面向短剧投流团队的专业创作工作台，将正片素材转化为“前贴钩子 + 正片高光 + 结尾钩子”的多版本广告成片。系统需要覆盖剧情理解、前贴脚本、前贴生成、高光智剪、审片合成和批量导出，并保留每个阶段的输入、版本、任务和产物。

## 产品边界

本次仅实现短剧投流专业创作，不扩展通用自由创作、一键复刻或其他广告品类。前贴支持反常台词、超自然猎奇、身份反差、生死危机四类钩子，以及剧情强关联、剧情延展、强引流三种类型。高光支持混剪、文字解说、旁白解说三种模式。

## 页面结构

1. 项目中心：剧目、素材状态、生产进度、成片数量和最近任务。
2. 创作流水线：正片上传、剧情理解、策略、脚本、前贴、高光和合成七个阶段。
3. 审片工作台：9:16 预览、前贴/高光/包装三轨时间线、版本切换和导出。
4. 素材库：源视频、分析结果、脚本、参考图、生成片段和最终成片。
5. 任务中心：异步任务状态、耗时、模型、错误摘要和单阶段重试。

## 技术架构

采用 Next.js 全栈单仓库、MySQL 和独立 Worker。浏览器只访问应用 API。大文件通过服务端签发的 TOS 上传地址直传对象存储。服务端将 Ark 文本、Seedream、Seedance、MediaKit 封装为供应商适配器，任务编排器维护阶段依赖和状态。

默认使用 mock provider 运行完整界面和自动化测试；配置环境变量后切换到真实 provider。任何密钥、数据库密码和上游完整响应都不得写入源码、前端或日志。

## 数据流

1. 用户创建项目并上传正片到 TOS。
2. Seed 2.0 输出人物、冲突、情绪曲线和高光候选的结构化 JSON。
3. 脚本生成器结合热点、钩子范式和前贴类型输出多个脚本与分镜版本。
4. Seedance 创建前贴视频任务，Worker 轮询或接收回调。
5. MediaKit 场景切分并生成高光片段。
6. 用户在审片页确定前贴、高光和包装轨。
7. MediaKit 拼接输出成片，产物转存 TOS 并记录版本。

## 状态与错误

任务统一为 `draft`、`queued`、`running`、`needs_review`、`completed`、`failed`、`canceled`。外部任务使用幂等键；超时采用指数退避；结构化输出通过 Schema 校验；单阶段失败不会清除已完成产物；临时 URL 在过期前转存或刷新。

## 安全

- 所有凭证仅从服务端环境变量读取。
- 上传限制 MIME、扩展名和大小，并使用随机对象 key。
- 日志只记录 provider、request id、耗时和脱敏错误。
- 对创建生成任务、重试和导出接口做鉴权、限流和审计。
- 已出现在飞书文档中的数据库密码、API Key、AK/SK 必须轮换后再使用。

## 验证

领域规则和 Schema 使用单元测试；Provider 使用契约测试；核心流程使用端到端测试。生产构建必须通过类型检查，mock 模式下从创建项目到生成成片的流程必须可运行。
